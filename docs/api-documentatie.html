AutoMaat — API-documentatie

REST-API voor het beheer van een autogarage: klanten, auto's, keuringen, reparaties, onderdelen en bonnen met btw.

Base URL: http://localhost:8080

Authenticatie

De authenticatie loopt via twee servers: Keycloak op poort 9090 geeft de tokens uit, de AutoMaat-API op poort 8080 valideert ze alleen. Je doet dus eerst een aanvraag bij Keycloak, en gebruikt dat token daarna bij de API.

Stap 1 — token ophalen bij Keycloak (poort 9090)
POST http://localhost:9090/realms/automaat/protocol/openid-connect/token
Content-Type: application/x-www-form-urlencoded

grant_type=password
client_id=automaat-api
client_secret=<jouw-client-secret>
username=kassa
password=geheim

Keycloak antwoordt met het token. Testgebruikers (wachtwoord geheim): kassa, monteur, backoffice.

{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCIgOiAiSl...",
  "token_type": "Bearer",
  "expires_in": 300
}
Stap 2 — API aanroepen met het token (poort 8080)

Stuur het access_token mee in de header bij elke aanvraag naar de API:

Authorization: Bearer <access_token>
200ingelogd + juiste rol 401geen of ongeldig token 403rol mag dit niet

Lezen (GET) mag elke ingelogde rol. Schrijven is per resource beperkt:

ResourceSchrijven
/customers, /cars, /invoicesCASHIER
/inspections, /repairsMECHANIC
/partsBACKOFFICE

Foutresponse

Fouten komen als JSON met status, error, message en timestamp; bij validatie extra fieldErrors.

{
  "status": 400,
  "error": "Bad Request",
  "message": "Validatie mislukt.",
  "timestamp": "2026-05-12T10:15:30.123Z",
  "fieldErrors": {
    "email": "E-mailadres is verplicht."
  }
}
